# İstanbul Site ve Yönetim Rehberi

Bölge ve ilçe bazlı site yönetimleri ile profesyonel yönetim firmalarının kamuya açık telefon numaraları.

## Dosya

- [Istanbul_Site_ve_Yonetim_Rehberi.pdf](./Istanbul_Site_ve_Yonetim_Rehberi.pdf)

## PDF’i yeniden üretmek

```bash
pip install reportlab
python3 scripts/generate_istanbul_site_rehberi.py
```

## Not

İstanbul’daki tüm sitelerin eksiksiz listesi değildir; kamuya açık kaynaklardan derlenen örnek bir rehberdir. Numaralar değişebilir.
